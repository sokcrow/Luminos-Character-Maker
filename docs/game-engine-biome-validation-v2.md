# Game Engine · Biome Validation V2

## Scope

This pass validates the seven regions that already exist on the current global hex map. It does not add new hexes, new biome profiles, basin generation, climbing, caves, tactical semantics, encounter anchors or AI.

Validation target:

`current global region -> BiomeComposer -> GeographyField -> GeologySystem -> Ecology/Hydrology -> owC runtime sector`

The goal is to prove that the existing biome definitions produce physically coherent local terrain before the biome system is expanded.

## Acceptance contract

`BiomeValidationV2` validates each active region using the same local `owC` sector.

Every region must satisfy:

- procedural generation audit passes;
- active biome profile matches the global region;
- active hydrology matches the region definition;
- at least one macroform is generated;
- required signed geography exists when hills/ridges/mountain/cliffs/rolling justify it;
- geology exists when rockiness/landforms justify physical geology;
- any accepted outcrop remains within the readable local area;
- geology route audit keeps all land anchors connected;
- the player-facing grid remains absent.

Additional profile checks:

- coast regions must contain sampled land and sampled water in the same local sector;
- forest regions must activate forest-biome generation and produce walk corridors.

## Desert exception

Costa Árida is not required to create shoulder/gully/saddle features merely to make `GeographyField.features` non-zero.

Its primary geographic forms are dunes and mesas, which are generated by `LandformSystem`. This prevents validation from forcing temperate-hill morphology onto the desert.

## Geology readability

Blocking geology remains connectivity-safe, but V2 adds a readability constraint.

When a sector requests blocking outcrops, the resolver first attempts to accept one valid candidate whose center is within 22 local tiles of the sector center. The candidate is still rejected if it overlaps protected zones or disconnects spawn/land transitions.

This fixes cases where a biome technically contained geology but all accepted formations were too far from the entry area to communicate its identity.
